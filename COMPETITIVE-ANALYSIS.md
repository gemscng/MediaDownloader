# Competitive Analysis — Video Downloader Market (Feb 2026)

## Competitors Studied

### Dead / Shutdown (DMCA/Copyright)
- **y2mate.com** — SHUTDOWN by IFPI for copyright infringement
- **yt1s.com** — SHUTDOWN by IFPI for copyright infringement
- These were the biggest players. Their death = massive SEO opportunity.

### Active Competitors

#### cobalt.tools ⭐ (Our closest competitor)
- **Vibe:** Minimalist, open-source, privacy-focused
- **UX:** Ultra-clean single input, no ads, no tracking
- **Strengths:** Trust, speed, open-source community, no watermark
- **Weaknesses:** No SEO content, no monetization, limited formats, no upload tools
- **Traffic:** Growing fast from Reddit/tech community

#### SaveFrom.net
- **Vibe:** Utilitarian, SEO-heavy
- **UX:** URL input + browser extension upsell
- **Strengths:** Massive SEO content (platform-specific pages), Chrome extension, brand recognition
- **Weaknesses:** Aggressive ads, popups, slow, outdated design, pushy extension install
- **Traffic:** Still huge from legacy SEO

#### SnapSave.app
- **Vibe:** Facebook-focused, clean-ish
- **UX:** Simple paste + download, 4K support
- **Strengths:** Facebook specialist (Reels, Stories, 4K), iOS instructions
- **Weaknesses:** Single-platform focus, basic design, no audio tools

#### ssstik.io
- **Vibe:** TikTok specialist
- **UX:** Clean, focused, good mobile experience
- **Strengths:** No watermark removal, HD download, good SEO (how-to guides)
- **Weaknesses:** TikTok only, some ads, no audio extraction

#### loader.to
- **Vibe:** YouTube MP3 specialist
- **UX:** Clean, format selector, playlist support
- **Strengths:** Playlist download, many formats (MP3/MP4/FLAC/OGG/WAV)
- **Weaknesses:** YouTube only, conversion queue system (slow), educational SEO bloat

## Gaps to Fill (What competitors do that we don't)

### Must-Have
1. **Playlist support** — loader.to's killer feature
2. **No watermark badge** — ssstik.io prominently displays "no watermark"
3. **Browser extension / bookmarklet** — SaveFrom's "ss" prefix trick
4. **4K support** — SnapSave advertises 4K prominently
5. **Format variety** — WAV, FLAC, OGG, WebM options
6. **Thumbnail download** — simple but high-demand feature
7. **Batch download** — paste multiple URLs

### Nice-to-Have
8. **QR code for mobile transfer** — download on PC, scan QR to get on phone
9. **Preview/player** — play video before downloading
10. **Download history** — local storage based
11. **API for developers** — freemium API access
12. **PWA support** — installable on mobile home screen
13. **Dark/light theme toggle**

## Winning Strategy

### vs cobalt.tools: We win on features (tools, trim, i18n, affiliate revenue)
### vs SaveFrom: We win on UX (no ads, modern design, faster)
### vs SnapSave: We win on platform coverage (6 vs 1)
### vs ssstik: We win on platform coverage + audio tools
### vs loader: We win on multi-platform + modern UX

## Key Insight
y2mate and yt1s being shut down created a MASSIVE vacuum. Their combined monthly traffic was 100M+. The opportunity is capturing their search traffic with:
1. Better SEO (platform-specific landing pages)
2. Better UX (no ads, fast, modern)
3. Better features (multi-platform, audio tools)
4. Legal resilience (.sh or .to domain, server outside US/EU)
